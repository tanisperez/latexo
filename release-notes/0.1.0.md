# Latexo 0.1.0

The first version of Latexo, a native system monitor for Linux and Windows.

## What it shows

- **Overview**: a card per resource with its value and live chart, the busiest processes and the
  power used today.
- **Processes**: sort by any column, filter yours or the system's, search by name or PID, end a
  process or its whole tree.
- **CPU** and **Cores**: usage (user and kernel on Linux), clock and load, and each core as bars,
  a heat map over time, a small chart per core or a map of the processor, with the temperature
  of each core where Linux gives it.
- **GPU**, **Memory**, **Disk**, **Network**, **Temperatures**, **Fans** and **Energy**, each with
  its chart, its details and the processes that use it most.
- **Alerts**: rules on temperatures, usage, full disks, power and fans, with how long they must
  last, shown in the window and as system notifications while the window is out of sight.

## How it looks and works

- Charts in four styles (line, bars, steps, dots) from the last minute to the last week. The
  last hour is kept sample by sample, and the average of each minute for a day or a week, saved
  on this computer.
- A floating pill with CPU, GPU, memory, power and temperature, always above the other windows,
  and an icon in the tray.
- Settings inside the window: sampling interval, history kept, theme, language, chart style,
  temperature unit, price of a kWh, start with the session, tray icon, floating pill, the
  sensors this computer gives, export and clear the history, log level.
- English, Spanish, Galician and Italian.
- Keyboard: `Ctrl+F` searches the processes, `Delete` ends the selected one, `Ctrl+,` opens
  Settings.

## Packages
