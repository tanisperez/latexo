# Translations

Languages: English (`en`, the source and the fallback), Spanish (`es`), Galician (`gl`) and
Italian (`it`), as Postino (whose `docs/i18n.md` has the reasons behind each decision).

## Files and keys

- One YAML file per area under `crates/latexo-app/locales/`: `common`, `units`, `nav`, `charts`,
  `overview`, `cpu`, `cores`, `gpu`, `memory`, `disk`, `network`, `temperatures`, `fans`,
  `energy`, `processes`, `alerts`, `settings`, `about`, `update`.
- Format `_version: 2`: every key lists its four translations together.
- Keys are dotted, area first, lowercase snake case. Plurals are two keys, `<key>.one` and
  `<key>.other`, read with `state::locale::plural`.
- Units are translated where languages differ: `units.percent` is `18%` in English and Italian
  and `18 %` in Spanish and Galician. Numbers go through `telaio_app::number` (`1,234.5` in
  English, `1.234,5` in the others).
- `rust-i18n` reads the files at compile time: after adding a file, touch `src/main.rs` or the
  binary keeps the old tables.

## Tests

`state/locale.rs` checks that every key exists in the four languages with the same placeholders,
that no translation has an em dash, that plural keys come in pairs and that every literal `t!`
key used under `src/` exists.
